## 🔴 第一部分:出門前必做(做不到就別飛)

### 1. 三個編譯開關的狀態

| 開關 | 位置 | 現在 | 飛行前必須 |
|---|---|---|---|
| `REMOTE_CMD_UNRESTRICTED` | `main.c:738` | **開 🔴** | **必須註解掉** |
| `PYRO_ADC_FITTED` | `main.c:154` | ✅ 開 | 維持(分壓電阻已焊,2026-07-27) |
| `LORA_MODE_PINS` | `lora_e22.c:37` | ✅ 開 | 維持(M0/M1 已改線,2026-07-27) |

**只剩第一項要動。**另外兩個已經啟用,不要再關掉——關掉會失去
保險絲/武裝電壓監測(`VF`/`VA`)與遠端換頻(`/setch`)。

**`REMOTE_CMD_UNRESTRICTED` 開著時,遠端開傘沒有任何閘門**——不需要 ARM、不管飛行狀態、可以無限重複點火。那是桌測用的。開著的版本一開機就會在 USB 和 LoRa 大喊 `UNRESTRICTED MODE - NOT FLIGHT SAFE`,**看到這句話就是不能飛**。

關掉的方法:把 `main.c:738` 的 `#define REMOTE_CMD_UNRESTRICTED` 前面加 `//`,重新編譯燒錄。
編譯時會噴 `#warning ... NOT FLIGHT SAFE`,**看到那行警告消失才算關掉**。

⚠ **兩塊板都要燒同一個設定。**

### 2. 燒錄後立刻接 USB 檢查開機報告

```
MOD: BMP=1 IMU=1 LORA=1  REF_PRESS=1013.25 hPa  CLK=HSE  RST=POWER-ON  VF=-1.00V VA=-1.00V
```

| 欄位 | 正常 | 不正常代表什麼 |
|---|---|---|
| `BMP=` | 1 | 0 = 氣壓計沒起來,開傘條件 A 失效 |
| `IMU=` | 1 | 0 = 慣性感測沒起來,開傘條件 B 失效 |
| `LORA=` | 1 | 0 = **模組沒回應**,整場收不到遙測 |
| `REF_PRESS=` | 950~1030 | 超出 = 氣壓計讀值有問題 |
| `CLK=` | **HSE** | `HSI-FB` = 晶振故障已降級,**板子要查** |
| `RST=` | POWER-ON | `BROWNOUT` = 電源瞬斷(接觸不良/撞擊)<br>`IWDG` = 看門狗(異常)<br>`NRST-PIN` = 有人按了重置 |
| `VF= / VA=` | **7~8.4V** | -1.00 = ADC 沒啟用(分壓已焊,不該再看到 -1)<br>接近 0 = **保險絲熔斷** |
| 若出現 `BUS=CLAMPED!` | 不該出現 | SPI2 匯流排被鉗位,**立刻斷電查線** |
| 若出現 `UNRESTRICTED MODE` | 不該出現 | **不能飛,回去關開關** |

**兩塊板都要各自檢查一次。**

### 3. 電火頭安全程序

規範 4.6:儲能裝置在有人靠近時必須有**兩個獨立事件**擋著。

- **整備/搬運/上架**:啟動開關 OFF(或點火線未接)= 安全狀態
- **人員撤離後**、依審查委員指示才武裝
- **武裝動作必須從遠處做**(拉繩拔銷/長桿),不可用手在箭體上接線
- 武裝後**任何人不得靠近火箭**

## 第二部分:地面站啟動

### 開機順序

```
1. 先插好兩個 LoRa dongle(915MHz 和 2.4GHz)
2. 確認 settings.json 的 COM 埠對得上(見下)
3. 雙擊 run_persist_backend.bat   ← 最常用:同時起後端+GUI
```

| 檔案 | 用途 |
|---|---|
| `run_persist_backend.bat` | **標準啟動**:後端常駐 + GUI,GUI 關掉後端還在 |
| `run_gui_only.bat` | 只開 GUI,接到已經在跑的後端(GUI 崩潰後重開用) |
| `run_backend_ch1.bat` / `ch2.bat` | 只開單一頻道後端(除錯用) |

### COM 埠設定

檔案 `settings.json`,現在是:

```json
ch1 → com11 @ 9600     (915MHz  E22)
ch2 → com7  @ 9600     (2.4GHz  E28)
```

**COM 號換插孔就會變。** 開機發現對不上,兩個辦法:
- 改 `settings.json` 後重開
- 或 GUI 裡打 `/port COM12`(只改焦點頻道,即時生效)

⚠ **兩個頻道絕對不能設同一個 COM 埠**——序列埠是獨佔的,設一樣會有一塊板無聲失聯。

## 第三部分:所有指令

在 GUI 最下方的命令列輸入,**必須以 `/` 開頭**。打 `/help` 可以隨時叫出清單。

### 連線類

| 指令 | 作用 |
|---|---|
| `/port <COM>` | 換焦點頻道的序列埠,例 `/port COM12` |
| `/baud <數字>` | 換鮑率(正常都是 9600) |
| `/connect` | 重新連線 |
| `/disconnect` | 停止序列通訊 |
| `/focus <ch>` | 切換焦點頻道,例 `/focus ch2` |

### 資料類

| 指令 | 作用 |
|---|---|
| `/reset-angle` | 地面端姿態歸零(火箭平放時做) |
| `/reset-data` | **開新的一場**:舊 CSV/log 封存,開新檔,畫面全清 |

### 校準類

| 指令 | 作用 |
|---|---|
| `/cal` | 焦點板氣壓歸零 + 地面姿態歸零 |
| `/cal_all` | **全部板**氣壓歸零 + 地面姿態歸零 ← 發射台上用這個 |

⚠ 只在 IDLE 受理,飛行中火箭會拒收。

### 🚨 緊急類(火工品)

| 指令 | 作用 |
|---|---|
| `/arm` / `/arm_all` | 遠端解鎖,**30 秒**視窗 |
| `/dpl` / `/dpl_all` | 強制開傘 |
| `/abg` / `/abg_all` | 開氣囊 |

**帶 `_all` 的會同時發給兩塊板,緊急時一律用 `_all`。**

### 換頻(硬體改線後才能用)

| 指令 | 作用 |
|---|---|
| `/setch <0-80>` | 換 LoRa 頻道,頻率 = 850.125 + ch (MHz) |

**合規頻道只有 CH70~74**(920~925MHz)。現用 **CH72 = 922.125MHz**。
撞頻時的順序建議:**CH73 → CH71 → CH74**(CH70 貼著法規邊界,最後才用)。

⚠ **火箭換頻後,地面端 dongle 必須跟著換,否則該板立刻失聯。**

## 第四部分:按鈕(地圖與 log 之間那一排)

```
焦點: [ch1][ch2] ┃ [傘 ch1][囊 ch1][傘 ch2][囊 ch2] ┃ [傘 ALL][囊 ALL] ┃ [校準 ALL] [☑Auto 跟隨]
```

| 按鈕 | 行為 |
|---|---|
| **焦點 ch1/ch2** | 切換圖表/地圖顯示哪塊板。單板指令(`/dpl` 等)會打到焦點板 |
| **傘/囊 各板** | 只對該板 |
| **傘 ALL / 囊 ALL** | 兩塊板同時 |
| **校準 ALL** | 氣壓歸零(單擊即發,靠火箭的 IDLE 閘門防誤按) |
| **Auto 跟隨** | 圖表自動捲動 |

### 點火鈕的兩段式保險

1. **第一次按** → 變紅、文字變「確認?」、開始 **3 秒倒數**
2. **3 秒內再按一次** → 才真的發射
3. **300ms 內的連按會被忽略**(防手抖/雙擊)
4. **3 秒沒有第二次按** → 自動解除

按鈕寬度是鎖死的,按下去**位置不會移動**,第二下不會誤點到旁邊。

## 第五部分:狀態燈與符號

### 每塊板的 LED(左下角)

| 顏色 | 意思 | 該做什麼 |
|---|---|---|
| 🟢 **綠** | 正常收資料 | — |
| 🟠 **橙(常亮)** | 後端在跑,還沒收到遙測 | 等/查天線/查火箭有沒有開 |
| 🟡 **黃(閃)** | **有資料流入但全部解析失敗** | **查裝置插對沒、鮑率對不對、頻段對不對** |
| 🟠 **橙(閃)** | 資料變舊(1.5~5 秒沒新資料) | 訊號變弱,注意 |
| 🔴 **紅** | 超過 5 秒沒資料 | RF 中斷 |
| 🟣 **紫(閃)** | 後端服務沒啟動 | 跑 `run_persist_backend.bat` |

**黃燈是最容易被誤解的**:它代表訊號有進來但看不懂,通常是**插錯 dongle**或**鮑率設錯**,不是天線問題。

### 狀態列符號

```
▶ch1 com11 ✔0.3s 🔒7.9V    ch2 com7 ◌無資料
```

| 符號 | 意思 |
|---|---|
| `▶` | 這是焦點板,單板指令會打到它 |
| `✔0.3s` | 正常,0.3 秒前收到資料 |
| `⚠2.1s` | 資料變舊 |
| `✖8s` | 失聯 8 秒 |
| `◌無資料` | 還沒收到過 |
| `⚠格式錯` | 有資料但解析失敗 |
| `🔓ARM28s` | **該板已武裝**,還剩 28 秒 |
| `🔒7.9V` | pyro 電源正常、未武裝(要 ADC 焊好才有) |
| `🔓武裝7.9V` | pyro 已武裝 |
| `🔴熔斷` | **保險絲斷了,這塊板點不了火** |

### 開傘確認訊息

| 訊息 | 意思 |
|---|---|
| `✅ [CONFIRMED] ch1 DPL verified` | **火箭確實收到並執行了** |
| `🚫 [ch1] DPL REJECTED by rocket: ...` | 火箭收到但拒收(後面會寫原因) |
| `🔴 [UNCONFIRMED] ch1 DPL 已送出但 10s 內未見下行確認` | **沒有任何回應**,可能上行中斷 |

**看到 UNCONFIRMED 不要慌**:另一塊板若正常,單傘仍可安全著陸。可以重發,但**不要因為單板未確認而中止任務**。

## 第六部分:飛行狀態機

```
IDLE(0) ──離架偵測──► LAUNCHED(1) ──開傘判斷──► DEPLOYING(2) ──1秒──► DEPLOYED(3) ──靜止──► LANDED(4)
```

| 狀態 | 顯示 | 意思 |
|---|---|---|
| 0 IDLE | 地面靜置 | 等待離架 |
| 1 LAUNCHED | 飛行中 | 監視高度與時間 |
| 2 DEPLOYING | **開傘訊號輸出中** | GPIO 拉高 1 秒 |
| 3 DEPLOYED | 開傘完成 | 等待落地 |
| 4 LANDED | 已落地 | 低功耗記錄(終點,不會再變) |

### 離架偵測

**合加速度 ≥ 2.5g 持續 200ms**。地面搬運甩動甩不出 2.5g,所以不會誤判。

### 開傘條件 `(A ∧ B) ∨ C`

| 條件 | 內容 |
|---|---|
| **A** | 氣壓高度低於最高點 10m(且最高點需 ≥20m) |
| **B** | 垂直速度持續向下 1.5 秒 |
| **C** | **離架後 18 秒**無條件強制開傘(備援) |

- A∧B 同時成立 = 頂點後確認下降,**最精確**
- C 單獨成立 = 感測器故障時的保底

### ★ 感測器故障時的降級規則(2026-07-30 改成不對稱)

| 死掉的 | 結果 | 為什麼 |
|---|---|---|
| **IMU 死** | **cond_A(純氣壓)單獨守門**,照常開傘 | 純氣壓無積分無漂移,峰值是單調閂鎖,假高點只會讓開傘變晚(安全方向) |
| **氣壓計死** | **主路徑整個關閉,退到 18 秒備援** | cond_B 用的 `kf2_v` 靠氣壓修正,氣壓一死就沒有修正源;滑行段近自由落體,加速度計讀 ≈0,連重力參考都失去 → 那個數字是漂移量不是量測值 |
| 兩者皆死 | 只剩備援 C | — |

> **舊版是對稱的(任一顆死掉就讓另一顆單獨決定)。已改掉**——用一個漂移中的
> 濾波器決定開傘,最壞情況是推力段誤觸 = 解體。

### 遙測上怎麼看降級

| `MOD:` | 意思 |
|---|---|
| **`F`** | 四個模組全活 ✓ |
| **`7`** | 🔴 氣壓計死(主路徑已關,只剩 18 秒備援) |
| **`B`** | 🔴 IMU 死(cond_A 單獨守門,仍會正常開傘) |
| `E` | SD 卡死(不影響開傘) |

`C:` 欄是開傘條件:`C:0` 正常飛行中 ／ `C:1` IMU 死 ／ `C:F` 兩條件皆成立(開傘)

### 實測時序(81 組模擬:3 推力 × 3 仰角 × 9 風況)

| | 離架偵測後 |
|---|---|
| 頂點出現 | 14.20 ~ **17.42 s** |
| C 備援觸發 | 固定 18.00 s |
| **最小餘裕** | **+0.58 s**(`T110_e81_W4`,頂點 1389m) |
| 主路徑 A∧B | 頂點 +1.55 s(「持續下降 1.5 秒」是瓶頸) |

**C 在 25/81 組會比 A∧B 早觸發**,幾乎全是 +10% 推力那組(T090/T100 各 0/27)。
**標稱馬達不會走 C。**看到備援訊息 = 馬達超推,或氣壓路徑失效。

> **`DEPLOY_TB_MS` = 18 秒是定案值,不要再調。**
> 加大能買到「上升段誤觸」的餘裕,但那個後果是良性的(頂點前 0.5 秒開傘 ≈ 5 m/s
> 幾乎靜止);代價卻是氣壓計全死時開傘衝擊從 37 → 47 m/s(負荷 1.6 倍,隨 v²),
> 而那條路徑沒有任何其他保護。

### 氣囊(2026-07-30 加了兩道防誤觸)

- 自動:**DEPLOYED 且點火後滿 6 秒**、撞擊 >5g **持續 30ms**,或進入 LANDED
- 整趟只自動觸發一次(斷電會重置)

**為什麼要延遲 6 秒**:開傘衝擊必定超過 5g。開傘時下降 6~37 m/s、傘繩拉伸約
0.25 m → 7g ~ 279g,**連最溫和的那組都超過門檻**。而 DEPLOYING→DEPLOYED 只等
1 秒,傘完全張開卻要 0.5~1.5 秒——衝擊峰值有相當機率落在監看窗內,氣囊會在
數百公尺高空充氣,真正落海時就沒氣囊了。代價只有 60m 高度。

**桌測不受此限**:`#CMD:GNDTEST_SALT3310#` 模式下維持即時觸發(規範 4.5.3 要求
氣壓/計時感測器地面驗證)。

### 自旋不可能誤觸氣囊

離心力要到 5g,IMU 裝在距軸心 1.5cm 處需要 **9.1 rev/s**;而陀螺量程 ±2000dps
只到 5.56 rev/s——**離心力到 5g 之前陀螺早就飽和了**。
判準:**GX/GY/GZ 沒貼在 ±2000 就不用擔心自旋。**

(而且自旋速率正比空速:burnout 200 m/s → 傘下 12 m/s,只剩 1/17;離心力隨 ω²
所以只剩 1/290。傘下要達 5g,上升段得先轉到 110 rev/s,不可能。)


### 為什麼只怕東風

回收區極度不對稱:**東邊 +2812 m,西邊只有 −52 m**。東風把火箭吹向西邊的陸地。

**每 1 m/s 東風把落點往西推 100~150 公尺**,而無風落點才 +400~600 m。

| 東風(模擬中的均勻風) | 落西界以西 | 落**發射台**以西 |
|---|---|---|
| 3 m/s | 0 / 9 | 0 / 9 |
| **4 m/s** | 1 / 9 | **4 / 9** 🔴 |
| 5 m/s | 8 / 9 | 8 / 9 |

東風 4 m/s 時已有 4/9 落在**發射台後方**——那裡是人員位置,比出界更嚴重。

### 反直覺:推力越大、仰角越垂直,越容易回陸地

```
T090  頂點 966m   飛行 175s   臨界東風 4.9 m/s
T100  頂點1149m   飛行 205s   臨界東風 4.5 m/s
T110  頂點1332m   飛行 235s   臨界東風 4.1 m/s  ← 最危險
```

飛得高 → 傘下時間長 → 風吹得久。**在 ±1° 公差內,寧可偏低(79°)不要偏高。**

### 箭身彎曲:方向是你可以控制的

仰角每偏 1° → 落點移動約 **46 公尺**。箭身接合處彎曲 β 度,效果等同飛行方向偏 β 度。

```
向西偏 0.4°  → 可能出界
向東偏 3.0°  → 最遠 1398m，東界 2812m，完全安全
```

**上架前把火箭放平在直的參考面上轉一圈,量出彎向哪一側,做記號,上架時朝【東】。**
零成本,而且比「想辦法把箭身弄直」實際得多。

### 南北風不用擔心

每 1 m/s 只推 90~147 m,要出南北界(±1890 m)需要 **13~21 m/s** 的風——那種風不會放行。

## 第七部分:現場故障排除

### 收不到遙測

```
1. 看 LED 顏色 → 紫 = 後端沒開,跑 .bat
                → 黃 = 插錯裝置或鮑率錯
                → 橙/紅 = 真的沒訊號
2. 接 USB 看火箭開機報告 → LORA=0 就是模組問題,不是地面站
3. 檢查兩個頻道有沒有設成同一個 COM 埠
4. 剛剛在 GUI 改過 COM port / 鮑率 / 按過重連嗎?
   → 2026-07-30 之前這會有約 10% 機率讓解析執行緒無聲死亡,已修
```

### 改完 COM port 就整個沒資料(但 raw log 一直在長)

**這個缺陷已於 2026-07-30 修掉**(`start()` 每次重建佇列)。若跑的是舊版地面站,
症狀是:序列埠照讀、raw log 檔案照長,但畫面完全靜止且沒有任何錯誤訊息。

```
處置:把該頻道的 backend daemon 視窗【整個關掉】,再重跑 .bat
     ⚠ .bat 會偵測 port 還被綁著就跳過,所以舊視窗一定要先關乾淨
```

判斷方法:raw log 檔案大小一直增加(表示序列埠正常)但 GUI 完全靜止。

### 只有一塊板有訊號

**這不是中止的理由。** 雙板是熱備援,單板仍可完成回收。繼續任務,記下來事後查。

### 顯示「保險絲熔斷」

代表誤觸發被並聯導線擋下來了(**人是安全的**),但那塊板的 pyro 電源已死,點不了火。

- **發射前**:換保險絲
- **發射後**:靠另一塊板,不要中止

### 資料看起來不對

- **Roll 一直往一個方向漂** = 正常。六軸無磁力計,積分必然漂移
- **兩塊板數字略有差異** = 正常。各自獨立感測、獨立開機
- **切換頻道後統計歸零** = 正常。每塊板有各自的統計,切回去就回來了

### GUI 當掉

跑 `run_gui_only.bat` 重開 GUI,**後端還在跑、資料不會斷**。

## 第八部分:發射台流程(建議)

```
□ 1. 兩塊板燒錄「UNRESTRICTED 已關閉」的韌體
□ 2. 各自接 USB 檢查開機報告:
       · BMP/IMU/LORA 全 1、CLK=HSE、無 UNRESTRICTED 字樣
       · WHO=xx      → 69/6A(LSM6DS3) 或 6C(LSM6DSO),記下來
       · AZ_BIAS=x.x → 必須在 ±0.02 g 以內。超過表示校準那 2 秒火箭在晃,
                        放著別碰、重開一次
□ 3. 電火頭啟動開關 OFF,確認在安全狀態
□ 4. ★量箭身接合處的彎曲方向(放平在直的參考面上轉一圈),做記號
□ 5. ★量風。東風 >2.5 m/s → 暫停(見放行判準卡)
□ 6. 火箭上架、固定,**彎曲側朝東**、仰角取公差下緣(79°)
□ 7. 地面站啟動,確認兩個頻道都是綠燈
□ 8. 打 /reset-data 開新的一場
□ 9. ★★ 按「校準 ALL」→ 確認兩板都回 MSG SUCCESS RECAL
       這一步不能省,也不能用早上開機時的基準:
       氣壓漂 1.2 hPa → 誤判離架後無法撤銷;漂 2.4 hPa → C 備援的
       20m 地面保護失效。在發射台等幾小時就可能漂到。

       ★★ **判準:地面上 `RH` 顯示的數字,就是漂移量。**
          火箭沒動高度卻不是 0,只可能是基準過期。
            RH  < 5 m  ✅ 正常
            RH ≥ 5 m   ⚠  重新校準
            RH ≥ 10 m  🟠 誤判離架已【無法撤銷】
            RH ≥ 20 m  🔴 C 備援的 20m 地面保護【已失效】
          地面站會自動跳這三級告警,不用自己盯著算。
          等待期間隨時看到告警就再校準一次。

□ 10. ★★★ 確認 **`ST:0`**、高度歸零、`MOD:F`、`C:0`
       **`ST:` 一定要是 0。**如果顯示 1(LAUNCHED)代表已經被誤判離架閂死了
       ——狀態機沒有回 IDLE 的路徑,而 t_fly 會一路累積。真正發射時高度一過
       20m(離架後約 2.1 秒、39~46 m/s)備援計時早就超過 18 秒 → **當場開傘
       → 結構解體**。看到 ST:1 就斷電重開,不要硬飛。
□ 11. 人員撤離
□ 12. 依審查委員指示,從遠處武裝(拉繩/長桿)
□ 13. 地面站確認顯示「🔓武裝」(需 ADC 硬體)
□ 14. 倒數、點火
□ 15. 全程監看:狀態 0→1、高度上升、頂點、狀態轉 2、高度下降
       ⚠ 標稱馬達應該走 A∧B。看到「backup timer」= 馬達超推或氣壓路徑失效
□ 16. 落海後可用「囊 ALL」(若氣囊未自動觸發;自動觸發要等點火後 6 秒)
```

## 附錄:遙測封包格式

```
T12345 SQ42 AX+0.012 AY-0.003 AZ+0.998 GX+0.10 GY-0.20 GZ+0.05
P1013.25 RH0.5 KH0.3 VZ+0.01 GA1.00 ST:0 MOD:F GPS:1,9 C:0
VF8.12 VA7.98 LAT+22.17485 LON+120.89272
```

| 欄位 | 意思 |
|---|---|
| `T` | 開機至今毫秒 |
| `SQ` | 封包序號(算掉包率;數字倒退 = 火箭重開機) |
| `AX/AY/AZ` | 加速度 (g) |
| `GX/GY/GZ` | 角速度 (°/s)。**貼在 ±2000 = 陀螺飽和** |
| `P` | 氣壓 (hPa) |
| `RH` / `KH` | 相對高度(**裸氣壓**,開傘條件 A 用它) / KF 融合高度 (m) |
| `VZ` | KF 垂直速度 (m/s),開傘條件 B 用它 |
| `GA` | 合加速度 (g) |
| `ST:` | **飛行狀態 0~4**(不是 12 態!`ST:2` = 正在放傘,不是點火) |
| `MOD:` | 模組存活 hex:**`F`**=全好、**`7`**=氣壓計掛、**`B`**=IMU 掛、`E`=SD 掛 |
| `GPS:1,9` | GPS 有定位,9 顆衛星 |
| `C:` | 開傘條件 hex:`0` 正常飛行中、`1` IMU 死、`F` 兩條件成立 |
| `VF` / `VA` | 保險絲後端 / 武裝後端電壓(**-1 = 未裝 ADC**) |
| `LAT/LON` | 經緯度(**只在有定位時出現**;宣稱定位卻沒這兩欄的幀會被降級) |

完整定義:`shared/protocol.h`(C)與 `ground_side/doc/telemetry_format.md`。

**發射場**:旭海 22.174847, 120.892723,向東發射(方位 90°)。
