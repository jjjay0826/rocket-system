## 開傘邏輯是怎麼演變的

v1.5（2026-02）的設計：

| 條件 | v1.5 的判據 | 角色 |
|---|---|---|
| A | 21 s < T < 23 s（時間在安全區間） | 主判斷 |
| B | 卡爾曼濾波後的氣壓高度 ≤ 850 m | 主判斷 |
| C | 加速度由正轉負並持續 | 輔助（視測試結果決定要不要用） |
| D | T > 25 s | 強制開傘 |

到 2026-08-01 實飛時已經改成 **(A ∧ B) ∨ C**：
A＝氣壓高度比最高點低 10 m、B＝垂直速度持續向下 1.5 s、C＝離架後 18 s 備援。
（B 在 8/1 用的是卡爾曼速度，那正是 ch2 主路徑失效的原因；8/7 才改成純氣壓微分。）

兩個主要改變：

- **高度門檻從「絕對值 850 m」改成「比最高點低 10 m」** —— 不管實際飛多高都成立，
  不必事先猜頂點高度
- **不再靠加速度判斷頂點** —— 滑行段加速度計只量到約 0.06 g，判斷不了方向
  （見 [`../flight_161_summary.md`](../flight_161_summary.md) 與
  [`../known_issues.md`](../known_issues.md)「已修好」裡姿態濾波那一條）
